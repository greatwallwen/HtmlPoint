# Dual-screen Task 6A report

- State: authenticated Helper-to-Host supervision, bounded asset transfer, redacted evidence, and failure cleanup are implemented and verified. This phase never assigned a display or opened a role window, so it makes no physical dual-screen certification claim.
- Install policy: the Helper resolves one fixed `projection-host/CourseStudio.ProjectionHost.exe` beneath a canonical non-reparse install root, holds non-replaceable Windows handles on the install directories and EXE while verifying SHA-256 and launching, uses one fixed argv entry with `shell=False`, and accepts only an optional Helper-owned canonical runtime root for development.
- Authentication: a random 32-byte bootstrap key crosses an inherited anonymous pipe and is absent from argv, logs, and disk. Host and Helper mutually authenticate nonces, derive a per-session key, then exchange strict LF-delimited JSON envelopes with direction, monotonic sequence, HMAC, duplicate-field rejection, and byte ceilings.
- Containment: the child starts suspended, joins a Windows Job Object configured with `KILL_ON_JOB_CLOSE`, and resumes only after successful assignment. Every failed-launch branch independently terminates an unassigned child. EOF, crash, timeout, cancellation, restart, and Helper shutdown close the transport and prevent an orphan; normal EOF receives a bounded grace interval to remove session temp files before the Job handle closes. Cancellation interrupts an in-flight receive rather than waiting behind the command lock.
- Asset boundary: one bundle is limited to 128 assets, 20 MiB per asset, and 96 MiB total. Transfers enforce allowed media types, one active asset at a time, a 36 KiB raw chunk ceiling, exact order and offset, declared size, and SHA-256. The Host exposes no committed asset before its final verification and deletes the staging session on shutdown.
- Evidence: atomic canonical JSON receipts contain only opaque identities, digests, generations, sequences, verification state, and stable error codes. Paths, bootstrap/session secrets, device identities, source code, and raw course content are rejected.
- Review: two read-only security passes closed executable replacement TOCTOU, pre-Job child execution, stale cached receipt replay, CRLF acceptance, interleaved asset state, and unassigned-child failure cleanup. The final pass found no Critical or Important issue.
- Verification: 24 focused Helper/publication tests passed with 2 explicitly integration-gated tests skipped; 36 non-integration .NET tests passed; the explicitly enabled real Host transport suite passed 23 tests through the production installed-host factory without window assignment; no Host process or newly created session temp directory remained; earlier empty project-specific temp directories were removed; and `git diff --check` passed.
