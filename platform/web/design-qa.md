## 主路径结论

1. 首屏只要求“资料 + 一句话”，开始组课是唯一主操作；内部课程、卡片、投影和运行清单 ID 不可见。
2. Markdown、PPTX 与 CSV 一次选择，开始后不出现手工发布知识卡或手工绑定图形步骤。
3. 风险被压缩为至多一个关注界面；接受建议后可继续到课程就绪。
4. 就绪页自动命名课程和知识单元，显示课时、章节和三份真实资料；章节标题不再带内部 `Goal n` 前缀。
5. 刷新后可从持久化 run 重开课程；编辑器显示原始文件名，并从同一已发布 Slide AST 加载真实来源图形。
6. 真实图形全部结束加载且无 fallback 后才通过；React 开发模式产生的受控工件取消单独计数，未发现意外同源失败、页面错误或控制台错误。
7. 授课入口保持“物理双屏认证：未认证”，没有用单屏或模拟结果冒充实体认证。

## 可访问性与响应式检查

- 图标控件使用真实按钮、可访问名称、`title` 和键盘焦点；抽屉支持 Escape 与焦点返回。
- 1440px 桌面直接显示来源栏；窄屏才显示“打开证据与来源”按钮。浏览器验收按真实响应式状态操作，不点击隐藏控件。
